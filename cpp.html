01 — EXERCÍCIOS

Prática de programação

Alguns exemplos de conceitos estudados durante o aprendizado de C++.

01

Funções

Criação de funções para organizar o código e realizar operações específicas. 

int calcularMedia(int a, int b) {
    return (a + b) / 2;
}

int main() {
    int media = calcularMedia(8, 10);

    cout << media;

    return 0;
}
Resultado: 9
02

Estruturas de repetição

Utilização de loops para repetir comandos enquanto uma determinada condição for verdadeira. 

for (int i = 1; i <= 5; i++) {
    cout << i << endl;
}
Saída: 1 2 3 4 5
03

Arrays

Armazenamento de vários valores relacionados dentro de uma mesma estrutura. 

int numeros[5] = {
    10, 20, 30, 40, 50
};

for (int i = 0; i < 5; i++) {
    cout << numeros[i] << endl;
}
Quantidade: 5 elementos
04

Ponteiros

Estudo de ponteiros e acesso ao endereço de uma variável na memória. 

int numero = 25;

int* ponteiro = &numero;

cout << *ponteiro;
Valor: 25
05

Struct

Organização de diferentes informações relacionadas em uma única estrutura. 

struct Aluno {
    string nome;
    int idade;
};

Aluno aluno;

aluno.nome = "Carlos";
aluno.idade = 18;
Aluno: Carlos
06

Condicionais

Utilização de decisões para executar diferentes partes do programa. 

int nota = 8;

if (nota >= 7) {
    cout << "Aprovado";
} else {
    cout << "Reprovado";
}
Resultado: Aprovado
